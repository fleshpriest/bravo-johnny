## Bravo Johnny
[Johnny Decimal](https://johnnydecimal.com/) is a system to organize your life.
Bravo Johnny is a collection of scripts to help maintaining a Johnny Decimal file system.

### Features
- Creates new directories based on your JDex.
- Populate your JDex & file system with automated [standard-zero](https://johnnydecimal.com/10-19-concepts/12-advanced/12.03-the-standard-zeros/) directories

### Quick Start
- Modify the values in env_renameMe.py
  - Note: by default, the [alternate layout for standard zeros (by Simone)](https://forum.johnnydecimal.com/t/the-standard-zeros/1558/12) is used
- Rename env_renameMe.py to env.py

### Notes
- The scripts are only designed to work with a directory style JDex (ala Obsidian, Bear, etc.)
- This repo is in development. Never test on data that you are unwilling to lose.
- No current method of handling removed or changed directories.
